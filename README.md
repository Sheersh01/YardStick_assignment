# Universal SaaS Copilot — Yardstick Internship Assignment

A Manifest V3 Chrome Extension and Agentic Backend that injects a natural-language AI Copilot into Trello. Built for the Yardstick Fullstack Developer Intern assignment.

This project demonstrates the ability to inject custom React UIs into existing SaaS applications, manage complex state, connect to a streaming AI agent backend, dynamically learn SaaS capabilities via HAR file parsing, and execute actions on behalf of the user using native session auth.

## Architecture 🏗️
- **Chrome Extension (`apps/extension`)**: Built with React, TailwindCSS, and Vite. Injects an interactive chat interface natively into Trello's DOM.
- **Agent Backend (`apps/backend`)**: Node.js/Express server powered by the **Vercel AI SDK**. Exposes a streaming SSE endpoint for the chat UI.
- **Skills Registry (`packages/skills`)**: The universal tool registry that the agent uses to interface with Trello's API. Includes the HAR-to-Skill automation parser.

## Setup & Installation 🚀

### 1. Prerequisites
Ensure you have Node.js (v18+) and npm installed.

### 2. Install Dependencies
This project uses npm workspaces. Run the following command from the root directory to install dependencies for all packages:
```bash
npm install
```

### 3. Environment Variables
Create a `.env` file in the `packages/` directory and add your API keys:
```env
# Required for the LLM to process natural language
GROQ_API_KEY="your_groq_or_openai_api_key"

# Required for the extension to identify the application to Trello (No login flow needed)
VITE_TRELLO_API_KEY="your_trello_api_key"
```

### 4. Build the Extension
Build the Chrome Extension via Vite:
```bash
npm run build -w apps/extension
```

### 5. Start the Agent Backend
Start the backend development server (runs on `http://localhost:3000`):
```bash
npm run dev -w apps/backend
```

## How to Load the Extension in Chrome 🧩

1. Open Google Chrome and navigate to `chrome://extensions/`.
2. Turn on **Developer mode** (toggle in the top right corner).
3. Click **Load unpacked** in the top left corner.
4. Select the `apps/extension/dist` folder from this project.
5. The extension is now loaded! Navigate to [Trello](https://trello.com) and open any board. You will see the floating Copilot button in the bottom right corner.

## Capabilities & Testing 🤖

Once the backend is running and the extension is loaded on a Trello board, you can use natural language to control Trello. The agent leverages your existing native browser session (no OAuth login required!).

Try asking the Copilot:
- *"What lists do I have on this board?"*
- *"Create a new list called 'QA Testing'."*
- *"Add a new card called 'Fix Login Bug' to my To Do list."*
- *"Move the 'Fix Login Bug' card to the Doing list."*

**Mega-Prompt Example:**
> *"Check what lists exist on this board, then create a new card called 'Final Demo' in my To Do list, and immediately move it to the Doing list."*

## Bonus: HAR-to-Skill Parsing 🧠

As per the assignment requirements, the agent's tools can be dynamically generated by parsing network traffic (`.har` files) of a human manually performing tasks in the SaaS.

To test the HAR parser:
1. Export a network trace from Chrome DevTools as a `.har` file and place it in `packages/skills/trello.com.har`.
2. Run the generator script:
```bash
npm run generate-skills trello.com.har -w packages/skills
```
3. A new `generated-skills.json` will be created containing the fully parsed OpenAI Tool Schema ready to be injected into the Agent's brain.
